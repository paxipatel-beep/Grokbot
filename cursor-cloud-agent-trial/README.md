# Cursor Cloud Agent Trial

This folder is the output of a trial run (2026-09-22) proving out **Cursor Cloud Agent** as an
alternative coding path to the existing **Fleet → Codex CLI** workflow.

This work was done using **Cursor Cloud Agent models**, not Codex CLI.

## Scope

This trial is intentionally minimal and safe:

- Added this `cursor-cloud-agent-trial/` folder with `README.md`, `USAGE.md`, and `hello.py`.
- No other project files were changed.
- No dependencies were added, nothing was deployed, and no refactors were made.

See `USAGE.md` for billing notes relevant to comparing this path against Fleet Codex CLI.
